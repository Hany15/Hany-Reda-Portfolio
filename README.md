## Structure

```
.
├── index.html            # English  (canonical, x-default)
├── ru/index.html         # Русский
├── ar/index.html         # العربية  (dir="rtl")
├── 404.html              # noindex fallback for GitHub Pages
├── robots.txt            # allows everything, points at the sitemap
├── sitemap.xml           # 3 URLs with reciprocal hreflang alternates
├── .nojekyll             # serve the tree as-is, no Jekyll pass
│
├── assets/
│   ├── css/main.css      # single stylesheet, RTL via logical properties
│   ├── js/i18n.js        # translation dictionary  (EN / RU / AR)
│   ├── js/main.js        # nav, modal, counters, background canvas
│   └── img/projects/     # real project screenshots, WebP @600w + @1200w
│
├── cv/
│   ├── cv_en.pdf         # generated by tools/generate_cv.py
│   └── cv_ru.pdf
│
└── tools/                # build tooling — not served
    ├── make.py           # full build (run this)
    ├── build.py          #   1. markup template from the data model
    ├── render.py         #   2. pre-render EN/RU/AR + sitemap/robots/404
    ├── generate_cv.py    # regenerates both CV PDFs
    ├── verify.js         # i18n parity, asset + link integrity
    └── seo_audit.py      # per-page SEO checks
```

`index.html`, `ru/` and `ar/` are **generated**. Edit the sources, not the output.

---

## Build

```bash
python tools/make.py
```

That runs the template build, pre-renders the three language pages, regenerates
`sitemap.xml` / `robots.txt` / `404.html`, then runs both check suites.

Regenerate the CVs (only when their content changes):

```bash
python tools/generate_cv.py
```

Preview locally — use a server, not `file://`, so directory URLs resolve:

```bash
python -m http.server 8000
```

Then open `localhost:8000`, `/ru/`, `/ar/`.

## Editing content

| I want to change… | Edit |
|---|---|
| Any visible text, in any language | `assets/js/i18n.js` |
| Project data, tags, metrics, repo links | `tools/build.py` (top of file) |
| Modal copy and screenshots | `tools/build.py` + `assets/js/main.js` (`PROJECTS`) |
| Colours, spacing, layout | `assets/css/main.css` |
| CV content | `tools/generate_cv.py` (`EN` / `RU` dicts) |

Every user-visible string is a key in `i18n.js` and **must exist in all three
languages** — `tools/verify.js` fails the build otherwise.

## Checks

```bash
node tools/verify.js      # translation parity, assets, links
python tools/seo_audit.py # titles, canonical, hreflang, JSON-LD, headings
```

`verify.js` asserts that every key referenced in the markup or built at runtime
resolves in EN, RU and AR, that no key is defined but unused, and that every
referenced image exists on disk.

`seo_audit.py` asserts self-referential canonicals, reciprocal hreflang with
`x-default`, correct `lang`/`dir`, Open Graph and Twitter tags, three JSON-LD
objects (`Person`, `WebSite`, `ProfilePage`), one `<h1>` per page, and that each
page ships real crawlable prose rather than JS-filled placeholders.

## Notes

- **Pre-rendered on purpose.** Text is baked into each page at build time, so
  crawlers and no-JS visitors get the full content and each language has its own
  indexable URL.
- **Accessibility.** Colour pairs are verified against WCAG AA (including over
  gradients), interactive targets are ≥44×44px, motion is gated behind
  `prefers-reduced-motion`, and the modal traps focus.
- **`_archive/`** holds media from the previous version of the site that the
  current design no longer references. It is git-ignored; delete it whenever you
  are sure you no longer want those files.
